Leonida Ledger — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a checklist saved in the browser with export and import, filters by kind, a spoiler setting that hides story trophies until earned, a roadmap to the platinum, and the one potentially missable trophy flagged. About 200 hours, one playthrough, no online trophies.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `app/` with any static file server and open `app/index.html`. It works with the network off.
